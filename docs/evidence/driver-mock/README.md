# Driver backend validation evidence

The source image build and complete optional-backend matrix passed at
[320986d / run 39364896183](https://github.com/sub-mod/amd-gpu-mock/actions/runs/39364896183).
Native logs below come directly from that run's artifacts. Other ARM64 logs
come from the isolated local Podman/Kind validation on a Fedora Linux VM.
They are captured output, not example success text generated by documentation.

| Evidence | What it establishes |
| --- | --- |
| [Native AMD64](native-amd64.log), [native ARM64](native-arm64.log) | All seven real-renderer profiles, card/render opens, libdrm capacity/name/memory layouts, error paths, dashboard recovery, unclean restart |
| [Allocated Pod](allocated-arm64.log), [memory layouts](memory-layout-arm64.log) | Actual DRA allocation and native workload calls through staged libdrm |
| [Focused DRA](focused-arm64.log) | Capacity constraints, init/main container identity and PCIe-root rules |
| [Provider restart](restart-arm64.log) | Actual SIGKILL, Kubernetes restart-count increment, readiness, fresh allocated consumer |
| [DPX allocation](allocated-dpx-arm64.log) | Actual DRA partition, 152 CUs and 96 GiB through libdrm |
| [Cleanup](cleanup-arm64.log) | Helm uninstall restores the protected underlying DRM device; only the new cluster is removed |
| [Discovery](discovery.log), [DPX discovery](discovery-dpx.log) | Unchanged AMD discovery against original renderer output |
| [Published provenance](published-images.json) | Source pin, image/index/config digests, AMD64/ARM64 checks and anonymous registry access |
